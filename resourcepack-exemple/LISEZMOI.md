# Exemple de resource pack / Resource pack example

**FR** — Copiez le dossier `assets/ramdomize_chest` dans votre resource pack, puis placez votre texture
dans `assets/ramdomize_chest/textures/item/loot_chest.png`. Le modèle fourni est un simple cube
légèrement plus grand qu'un coffre vanilla : remplacez-le par votre propre modèle (Blockbench) si besoin.
Utilisez le `pack.mcmeta` de votre pack existant (format adapté à votre version 26.x).
Activez ensuite `visual.enabled: true` dans `config.yml` et lancez `/rchest visuals refresh`.

**EN** — Copy the `assets/ramdomize_chest` folder into your resource pack, then put your texture in
`assets/ramdomize_chest/textures/item/loot_chest.png`. The provided model is a plain cube slightly larger
than a vanilla chest: replace it with your own model (Blockbench) if needed.
Use the `pack.mcmeta` from your existing pack (with the format matching your 26.x version).
Then set `visual.enabled: true` in `config.yml` and run `/rchest visuals refresh`.
